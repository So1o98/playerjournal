Player Journal adds a true RPG progression system to the game. Players start with 4 pages. Vitality, Agility, Combat and Defense. Players can unlock more pages of the journal to advance in professions.

Play together with friends each choosing different classes. Everyone gets to level up the basics such as health (vitality) defense, combat and agility but players will need to choose a specialization. Players can choose to be a miner, farmer, smither or a fisherman depending on what your world needs. Eventually players can master all these skills.

Each skill levels up as you play. No skill points, no skill trees. Your character progressess as your world progresses.

Features

Unique progression system which levels up as you play.
QOL features such as pinning xp to chat log.
Inspect other players Journals using shift+right click with an empty hand.
Server announcements when players hit milestones.
Config

The mod features a faily simple to use config to adjust/add custom restrictions into the journal making it easy to adjust any balancing concerns you may have.
Custom item in config example...

"mod:itemid;class:lvl;optional second class:lvl"
"mod:itemid;combat:1;vitality:2"
"vc_gliders:paraglider_wood;agility:5"
Or a crafting restriction like this

"mod:itemid;class:lvl;xp"
"mod:itemid;smithing:10;15"
"archers:ranger_armor_chest;smithing:6;20"
Or the same system can be used to edit the already implemented vanilla items
